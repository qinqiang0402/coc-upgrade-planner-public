# 部落冲突升级规划器（第一版）

一个独立运行的中文升级时间计算器，暂不需要 Codex、账号登录或服务器。包含逐级升级明细、黄金令牌与额外加速（回归玩家或夯木节）、工人队列估算，以及多个命名方案的保存、备注和比较。方案备注可在升级清单下方编辑，并随方案切换、导出和导入。夯木节按官方 2025 年公布的 50% 减时减费规则模拟，不表示活动当前生效；家乡的超级充能和精工防御不适用，与黄金令牌叠加时按相乘估算。

需要看 17 本时，点击页面上方“查看 17 本升级数据”，或在“大本营阶段”选择 `TH17`；会显示大本营 16→17、地狱火炮 1→5 等标记为 17 本阶段的升级项目。地狱火炮 1 级随大本营获得，不另计建造；升级费用与时间以用户提供的逐级参考表为准。阶段筛选不限制方案中已有项目。

家乡建筑工人数量可选择 1–7；并行时间按所选工人数量估算。旧方案中保存的助手和哥布林加成不再参与计算，升级项目及备注不受影响。

## 先看看

直接双击 `index.html` 即可在浏览器打开。方案通常保存在当前浏览器；不同浏览器对本地文件存储的支持可能不同，保存后请用“导出备份”留一份 JSON。之后可在另一浏览器“导入备份”。旧 Codex 小组件中的方案不会自动搬到这个独立网页。

如果电脑安装了 Node.js，也可在本目录运行 `npm start`，然后访问 `http://127.0.0.1:4173`。通过本地网页服务或以后放到 HTTPS 网站时，可作为 PWA 安装并离线使用；双击本地文件虽然能使用计算器，但不能安装 PWA。

## 数据可靠性

当前有 253 个项目，**不是已逐项验证的最新版数据库**。19 本只补入部分上线前参考数据，尚未在游戏内核对；本次更新对旧等级时间和费用的调整也未全面更新。已知 Diggy 11–15 级及大量 19 本等级尚未收录。请先看 [数据来源和校正规则](DATA_SOURCES.md)，并以游戏内实际显示为准。

## 维护

项目不依赖第三方 npm 包。

```text
npm run build:data   生成网页使用的数据文件
npm test             检查数据结构与关键升级案例
npm start            在本机预览
```

主要文件：`index.html` 是界面，`styles.css` 是样式，`app.js` 是计算与交互，`data/*.json` 是数据源，`scripts/build-data.mjs` 负责构建。项目使用 GitHub 仓库保存代码；尚未发布为公开网站。
